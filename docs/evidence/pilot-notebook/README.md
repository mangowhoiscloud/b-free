# 파일럿(노트북) 기록

노트북 Docker Compose 파일럿(`bravo-pilot`)에서 2026-11-02 18:40–20:30 KST에 돌린 실행 기록입니다. **클라우드 결과가 아닙니다.** Compose 파일럿은 팀장 지시로 내렸습니다(`deploy/CLOUD-E2E-CONTRACT.md` 6.1). 데모와 문서에서는 이 기록을 "파일럿(노트북) 기록"으로만 인용합니다.

원본은 `deploy/pilot/runs/`(Git 제외)에 있었습니다. 감사 B22(`docs/review/stub-audit-2026-11-02.md`)에 따라 그대로 복사해 커밋 대상에 둡니다. 파일은 고치지 않았습니다. 복사 전에 비밀번호 · 토큰 모양 값이 없는지 확인했습니다. `password`가 들어간 줄은 통제 질문 문장뿐입니다.

## 판정

실행마다 판정은 [RUNS.tsv](RUNS.tsv)에 있습니다. 판정 기준은 아래이고, 실행 파일의 값만으로 셉니다.

| 시나리오 | PASS 기준 |
|---|---|
| match | 컷오버 `DONE`, 영수증 `MATCH`, 부하 요약의 NFR-2 `ok` |
| mismatch | 불일치를 심은 뒤 `ABORT_PRE_WRITE`, 영수증 `MISMATCH`, `write_pause_ms`가 `null`, NFR-2 `ok` |
| roundtrip | match 기준 + 되돌리기 `DONE`과 `MATCH` + S4-AC1(목적지에서 쓴 행의 수와 해시가 출발지와 같음) |
| match+채팅 | match 기준 + 채팅 트래픽 파일이 비어 있지 않음 |
| contract E1–E6 | 시험별 판정 줄이 있어야 함. 지금 파일에는 출력만 있음 |

## 요약

- 컷오버 `DONE` 실행의 쓰기 정지: 76, 80, 87, 92, 94, 101, 105, 139 ms(8회). 부하는 초당 20건, 40초입니다. 스펙 기준 50 req/s로 잰 기록은 없습니다.
- FAIL 셋: `smoke-20261102T191253`(S4-AC1 목적지 314행, 출발지 599행으로 다름), `smoke-20261102T194436`(채팅 트래픽 파일이 비었고 부하 요약이 없음), `contract-20261102T191626`(e4만 있는 불완전 실행).
- 불일치 주입 셋(`184416`, `192634`, `194650`)은 기대대로 `ABORT_PRE_WRITE`입니다. `write_pause_ms`는 `null`이고, 단계 시간 합은 61, 66, 82 ms입니다.
- 계약 시험 넷은 "보류"입니다. 시험별 판정 줄이 없고, 감사 B12 · B13이 판정 방법의 결함을 지적했기 때문입니다.
