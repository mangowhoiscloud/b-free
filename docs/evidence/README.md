# 증거

측정과 시험 결과를 남깁니다. 모든 행에 실행 ID, 시각(UTC), 커밋, 환경을 붙입니다. 데모에서 "미리 실행한 것"은 여기 있는 실행 ID와 시각을 보입니다(스펙 §10).

| 파일(계획) | 내용 | 작업 |
|---|---|---|
| `cutover.tsv` | 쓰기 정지 ms(단계별), 실패 · 유실 · 중복, 영수증 ID | T12, T25 |
| `controls.tsv` | 환경별 통제 시험 결과 | T14 |
| `rehearsals.tsv` | 리허설 결과, 차단 건수, 검증 판정 | T15, T26 |
| `isolation.tsv` | 리허설 격리 시험 결과 | T3 |
