# T24 · 팀 데모 가이드

2026-11-03 공유판. 이 페이지는 개인 구현 `b-free`를 팀원이 살펴보는 경로입니다. 팀 정본의 인수 완료를 뜻하지 않습니다.

## 시작

1. [운영 콘솔](https://b-free.mangowhois.ai/)에서 팀 Slack에 등록한 이메일을 입력하고 메일로 받은 One-time PIN으로 로그인합니다. 팀 리뷰 계정은 조회 권한(`viewer`)입니다.
2. **홈 → 클러스터**에서 출발지 AWS EKS, 목적지 온프렘 RKE2, 추가 목적지 GKE의 수집 시각과 상태를 확인합니다. 중앙 플랫폼은 별도 EC2/RKE2입니다.
3. **데모 앱**을 열거나 [리뷰용 채팅방](https://b-free-chat.mangowhois.ai/?room=team-review-20261103)으로 이동합니다. 채팅에 보일 이름을 정한 뒤 시험 문구를 보냅니다. 주소의 `room` 값으로 방을 구분할 수 있습니다. 공용 데모이므로 실제 업무·개인정보는 넣지 않습니다.
4. **관측 → 비용 영수증 → 기록 재생**으로 이동합니다. 데이터의 수집 시각과 누락 표시를 함께 봅니다. 비용은 일부 출처만 연결된 추정치이며, 현재 콘솔 로그·트레이스 목록은 미연결입니다.
5. [README의 로드맵](../../README.md#로드맵-대비-구현-현황)과 [리뷰·결함 목록](REVIEW-STATUS.md)을 대조합니다. 과거 측정은 [증거 색인](../evidence/README.md)에 있습니다.

## 화면에서 구분할 것

| 화면·기능 | 볼 수 있는 것 | 아직 완료로 볼 수 없는 것 |
|---|---|---|
| 홈·클러스터 | 실제 환경 목록, 최근 수집, 서비스 응답 | 모든 통제 시험 PASS, 이전 완료 |
| 데모 앱 | 실제 채팅 쓰기·읽기, 현재 환경의 응답 | 부하 중 DB 컷오버·복구 |
| 관측 | 서비스 상태와 수집된 메트릭, 외부 Grafana 링크 | 모든 로그·트레이스의 콘솔 통합 |
| 비용 | 연결된 출처의 사용량·가격 추정, 제외 항목 | 최종 청구액, 전체 클라우드 비용 |
| 계획·승인·실행 | 구현된 흐름, 현재 저장된 기록 | 사람 승인을 포함한 전체 E2E 성공 기록 |

## 권한과 키

- 조회는 각자 이메일 로그인으로 합니다. 저장소 복제나 키 다운로드는 필요 없습니다.
- 계획 생성·실행 시작은 운영자, 승인은 별도 승인자가 수행합니다. 리뷰 계정에는 이 권한을 주지 않습니다.
- 클라우드·LLM 실행 비밀은 플랫폼 OpenBao와 Kubernetes Secret에 보관합니다. CI는 GitHub OIDC와 `GITHUB_TOKEN`을 사용합니다. [접근 설정](../../deploy/platform/access/README.md)
- LLM 키가 연결돼 있어도 공급자 사용 한도와 실행 권한은 별개입니다. 마지막 Opus 작업은 주간 한도에 도달해 중단됐으며, 추가 리허설을 성공한 것으로 표시하지 않습니다.

## 리뷰 남기는 형식

화면 또는 실행 ID, 확인 시각, 기대한 동작, 관찰한 동작, 재현 순서를 함께 남깁니다. 응답에 토큰·개인 메일·쿠키가 있으면 제거합니다. 구현을 팀 저장소로 옮기는 범위는 계약과 인터페이스를 함께 검토한 뒤 결정합니다.
