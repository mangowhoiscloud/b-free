# 프롬프트 목록

프롬프트는 사람이 고칩니다. 에이전트는 이 폴더를 고치지 않습니다.

| 파일 | 읽는 코드 | 용도 | 마지막 평가 |
|---|---|---|---|
| `rehearsal-agent.md` | 없음(준비 중) | 쓰지 않습니다. 시스템 프롬프트는 `bravo_agents.envelope.render_system_prompt`가 역할 허용 목록과 상태 봉투로 만듭니다(`platform/agent`) | 없음 |

프롬프트를 바꾸면 같은 task로 Job을 다시 돌리고, `docs/evidence/rehearsals.tsv` 행을 위 표에 적습니다.
