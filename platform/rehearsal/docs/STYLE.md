# 문체

팀 STYLE.md 위에 ASD-STE100 문장 규칙을 약 80%만 얹습니다. lint를 통과해도 "STE 준수"라고 부르지 않습니다.

## 설명문

- 한 문장에 정보 하나를 씁니다. 90자 이하로 씁니다.
- 결론을 첫 문장에 둡니다.
- 같은 대상은 같은 용어로 부릅니다. 용어는 처음 나올 때 한국어(영문)로 정의합니다.
- 명사는 세 개까지만 잇습니다. 세미콜론은 쓰지 않습니다.
- 본문에서 물결표, 화살표, 슬래시 나열을 쓰지 않습니다.

## 절차문 (지시 파일, 런북)

- 한 문장에 지시 하나를 씁니다. 70자 이하로 씁니다.
- 조건은 문장 앞에 둡니다. 예: "결과가 비어 있으면, 로그 끝 50줄을 읽습니다."
- 금지 사항은 "수준 단어, 지시, 이유" 순서로 씁니다. 예: "금지: verifier/를 고치지 않습니다. 판정 기준이 바뀌기 때문입니다."
- "클릭하라" 대신 실행할 명령을 적습니다.

## 근거 표시

- 수치, 버전, 날짜에는 출처를 붙입니다.
- 확인한 것과 추정한 것을 문장 안에서 나눕니다("확인했습니다", "추정입니다").
